# Go-Game

## Sobre o projeto
Go é um jogo de tabuleiro milenar que se originou na China há mais de 2.500 anos. O objetivo é cercar mais território que o oponente. Este projeto busca recriar a experiência do jogo digitalmente.

## Como jogar
1. Coloque pedras nas interseções do tabuleiro.
2. Capture as pedras do oponente cercando-as completamente.
3. Crie territórios cercando espaços vazios para obter pontos.

## Tecnologias utilizadas
- **TypeScript** (93%)
- **HTML, CSS e JavaScript**
- **TailwindCSS**
- **Vite**

## Estrutura do repositório
O projeto contém:
- Código-fonte do jogo na pasta `src`
- Configurações do ambiente de desenvolvimento
- Arquivos de estilos e lógica de jogo
